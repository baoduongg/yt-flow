Hướng dẫn thiết lập hệ thống (Setup Wizard)

Chào mừng bạn đến với yt-flow. Hãy hoàn tất các bước bên dưới để kích hoạt hệ thống tự động hóa video.

Hoàn thành: 0/4 bước

1 Trình duyệt Google Chrome
Đang kiểm tra...

Playwright điều khiển Google Chrome thực tế để tự động tạo video trên Gemini. Bạn cần cài đặt Google Chrome trên máy tính của mình.

Không tìm thấy Google Chrome tại các thư mục ứng dụng mặc định. Vui lòng tải và cài đặt từ trang chủ Chrome.
Đã phát hiện Google Chrome trên hệ thống của bạn!
2 Khởi tạo cấu hình (.env)
Chưa có

Môi trường chạy cần file .env để lưu trữ các cấu hình bảo mật.

Đã tạo file .env thành công!
3 Đăng nhập Gemini trên trình duyệt
Chưa đăng nhập

Vì lý do bảo mật của Google, bạn cần đăng nhập tài khoản Google của bạn bằng Chrome thật một lần để lưu phiên hoạt động.

Mở terminal trong thư mục dự án và chạy lệnh sau:

npm run gemini:login

Trình duyệt Chrome sẽ hiện ra. Hãy đăng nhập tài khoản của bạn, sau đó quay lại terminal nhấn Enter để kết thúc.

Chưa đủ
